# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within CampusPulse:

1. **Do not create a public issue** on GitHub.
2. Email the maintainers directly at `security@campuspulse.srmist.edu.in`.
3. Include details of the vulnerability, reproduction steps, and potential impact.
4. We acknowledge reports within 48 hours and work with you on responsible disclosure.
